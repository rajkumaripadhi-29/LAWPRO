# LAWPRO – Indian Law Legal Assistant

LAWPRO is an AI-powered legal assistance project designed to provide users with information and assistance related to Indian law.

The project combines a web-based frontend with a Python backend and an AI model trained/adapted for Indian legal-domain question answering.
.
## Features

- Indian law focused AI assistant
- Interactive web-based interface
- Question and answer functionality
- Python Flask backend
- Custom Indian-law model
- Legal-domain training data
- API-based communication between frontend and backend

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- Hugging Face Transformers
- Qwen2.5
- PyTorch
